# Scott Basedow Mechanical Engineering Portfolio v2

Mechanical-focused GitHub Pages portfolio for a Mechanical Engineering + Physics double major.

## Before publishing
1. Add your resume as `resume.pdf`.
2. Replace the LinkedIn URL.
3. Replace the GitHub URL.
4. Optionally replace the CSS rover illustration with real Fusion 360 screenshots/renders.

## Updating your existing GitHub Pages site
Upload/replace:
- `index.html`
- `style.css`
- `script.js`
- `resume.pdf`

Commit the changes. GitHub Pages will automatically update from the same branch.
