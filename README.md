# Scott Basedow Engineering Portfolio

A responsive engineering portfolio website built for GitHub Pages.

## Files

- `index.html` — site content
- `style.css` — complete responsive styling
- `script.js` — mobile navigation, scroll reveal, current year

## Before publishing

Open `index.html` and replace:

- `YOUR_EMAIL_HERE`
- LinkedIn URL
- GitHub URL

You can also add a resume by putting `resume.pdf` in this folder and adding a link such as:

```html
<a class="btn btn-secondary" href="resume.pdf" target="_blank">Resume</a>
```

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `engineering-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**.
6. Save.
7. GitHub will provide the public website link after deployment.

## Custom domain

If you later buy a domain, GitHub Pages can use it from the same Pages settings screen.
