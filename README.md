# Scott Basedow Engineering Portfolio — Final Recruiter Version

This version is designed as one integrated Mechanical Engineering + Physics portfolio rather than separate mechanical and physics identities.

## Site structure
- `index.html` — recruiter-focused homepage
- `projects.html` — scalable projects gallery
- `project-exodus.html` — EXODUS rover case study
- `project-alien.html` — Python project
- `experience.html` — professional experience
- `experience-sector.html` — detailed Sector Microwave experience
- `technical-writing.html` — formal physics lab report / technical writing area
- `resume.pdf` — current resume
- `assets/` — rover renders, drawings, and project images

## Uploading to GitHub Pages
Upload **everything inside this folder** to the root of the existing `engineering-portfolio` repository and replace older files. The `assets` folder must be uploaded too.

## Future updates
When you complete a new major project, add it to `projects.html` and create a dedicated case-study page only if the project is substantial. When the upper-division physics lab report is complete, replace the placeholder on `technical-writing.html` with the final PDF and selected plots.
